
# ClayStory AI

An AI-powered clay-style animated storytelling video generator for TikTok and Instagram.

## Goals
- Generate educational video scripts
- Create six-scene storyboards
- Animate handmade clay-style visuals
- Add narration and captions
- Export vertical MP4 videos

## Tech Stack
Next.js, TypeScript, Tailwind CSS, and Remotion.
